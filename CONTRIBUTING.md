## Project Setup

> \[!WARNING]\
> If you do not follow these steps and complain about the project not working, you will receive a lawsuit within 3-5 business days.
>
> Prepare your lawyers

1. Ensure Node.js is installed on your machine

2. Clone the repository

3. Create a `.env` file in the root of the project

> \[!NOTE]\
> Make sure you prepend a protcol `(http/https)` and append a `/`

```sh
NUXT_PUBLIC_BACKEND=http://127.0.0.1:8000/
```

4. Install dependencies and run locally

```sh
npm install
npm run dev
```

> \[!TIP]\
> Install the recommended [VSCode extensions](./.vscode/extensions.json).
>
> ESLint - Shows ESLint in the editor without needing to run the CLI command
>
> Prettier - Formats your code without needing to run the CLI command
